# DinoScape downloads

Builds of DinoScape, our offline / LAN version of [2006Scape](https://github.com/2006-Scape/2006Scape).

**Download:** open [Releases](../../releases/latest) and get `DinoScape-Windows-x64.zip`.
Unzip it somewhere you can write to (Desktop or Documents), then double-click `DinoScape.exe`.
Java is included. The launcher updates itself from this page when a new version is published.

DinoScape is free software under the GNU GPL v3, like 2006Scape.
Each release includes `DinoScape-source-vX.Y.Z.zip` with the complete source for that build.
